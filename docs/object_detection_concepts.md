# 객체 탐지 기초 개념

이 문서는 PTZ 프로젝트의 MobileNet-SSD 후처리에 나오는 개념을 코드와 연결해
설명한다. 현재 적용값은 [person_detector.cpp](../pi/camera_stream/src/person_detector.cpp)에
있다.

## 신뢰도 기준

모델은 찾은 물체마다 종류, 위치 박스, 신뢰도 점수를 낸다. 현재 코드는 종류가
`person`이고 신뢰도 점수가 `0.55` 이상인 결과만 남긴다.

```cpp
constexpr float kConfidenceThreshold = 0.55f;
```

코드에서는 모델 결과의 점수 `row[2]`가 이 값보다 낮으면 건너뛴다. 이 점수는
모델의 판단 점수이지, 실제 정답률을 그대로 보장하는 확률은 아니다.

기준을 높이면 애매한 탐지를 더 많이 버려 엉뚱한 대상을 잡는 일이 줄 수 있지만,
멀리 있거나 어두운 곳의 사람도 놓칠 수 있다. 기준을 낮추면 더 많은 사람 후보를
유지하지만, 사람 아닌 물체나 불확실한 박스가 남을 수 있다.

## 겹친 박스를 재는 법: IoU

신경망이 한 사람 주위에 박스 여러 개를 내놓을 수 있다. 두 박스가 실제로 얼마나
겹치는지 재는 대표적인 값이 **IoU**다. 두 박스가 겹치는 면적을 두 박스를 합친
전체 면적으로 나눈다.

```text
IoU = 겹치는 면적 / 두 박스의 합친 면적
```

IoU는 0에서 1 사이 값이다. 0이면 겹치지 않고, 1이면 두 박스가 완전히 같다.
“한 박스의 면적 중 몇 퍼센트가 겹쳤는가”와는 다른 계산이다.

예를 들어 가로·세로가 각각 100픽셀인 같은 크기의 박스 두 개가 가로 방향으로
20픽셀 어긋났다면 겹치는 부분은 80×100=8,000픽셀이고, 합친 영역은
100×100 + 100×100 − 8,000 = 12,000픽셀이다. 따라서 IoU는 약 0.67이다.

## 중복 박스 정리: NMS

**NMS(Non-Maximum Suppression)**는 겹치는 박스가 같은 물체를 가리킨다고 보고
중복을 정리하는 절차다. 현재 코드는 신뢰도 점수가 높은 박스를 우선 남긴다.

예를 들어 A 박스의 점수가 90%, B 박스의 점수가 72%이고 두 박스의 IoU가 0.67이면,
현재 기준 0.45보다 더 많이 겹치므로 A를 남기고 B를 제거한다. 반대로 IoU가 0.45
이하라면 NMS는 두 박스를 모두 남긴다. 둘이 다른 사람일 수 있기 때문이다.

```cpp
constexpr float kNmsThreshold = 0.45f;
cv::dnn::NMSBoxes(boxes, scores, kConfidenceThreshold, kNmsThreshold, keep);
```

여기서 `kNmsThreshold`는 사람인지 아닌지 판단하는 값이 아니다. **신뢰도가 높은
박스를 남긴 뒤, 다른 박스와 어느 정도 이상 겹치면 중복으로 버릴지** 정하는 값이다.

기준을 낮추면 조금만 겹쳐도 박스를 버려 중복은 줄지만, 가까이 서 있는 서로 다른
사람 중 한 명의 박스를 지울 가능성이 커진다. 기준을 높이면 가까운 사람을 각각
남기기 쉽지만 같은 사람의 박스가 여러 개 남을 수 있다. `0.45`는 현재 프로젝트의
초기 설정값이며 모든 장면에서 최적이라고 확정된 값은 아니다.

## 두 기준이 적용되는 순서

```text
모델 결과
  → person 종류만 선택
  → 신뢰도 0.55 미만 결과 제거
  → 남은 박스들의 IoU 비교
  → NMS 기준 0.45보다 많이 겹치는 중복 박스 제거
  → 남은 사람 박스를 PTZ 제어에 사용
```

신뢰도 기준은 “이 후보를 받아들일까?”를 정하고, NMS 기준은 “받아들인 후보끼리
같은 사람을 중복해서 가리키고 있을까?”를 정한다. 둘 다 고정된 물리 법칙이 아니라
탐지 성향을 조정하는 설정값이다. 실제 영상에서 사람을 자주 놓치거나 중복 박스가
많이 보이면 탐지 로그와 장면을 확인하고 조정해야 한다.
