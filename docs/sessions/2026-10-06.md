# 2026-10-06 처리 구조 계측과 예비 시험

## 구현

- 공통 성능 CSV: steady_clock 시간, PID/TID, 처리 시간, 부모 이벤트 연결.
- 카메라: 추론/프레임 나이/오래된 결과, 송출 단계 버퍼, 상태 조회 대기 시간,
  큐 상태 계측. 환경변수로 OpenCV 추론 스레드 1/2/3 선택.
- 서보: TCP 명령, 키 입력, 버튼 콜백/debounce, GPIO 호출 반환 계측.
- 별도 C++17 도구: 프로세스/스레드 자원 수집, 요약, 합성 영상의 동기/비동기 비교.
- Bash 도구: 조건별 실행과 모델/실행 환경/원본 저장.

## 시험과 판단

6조건을 각각 20초 실행하고 처음 5초를 제외했다. 최신 비동기 조건은 약 30버퍼/s,
공유 경로 동기 조건은 약 11버퍼/s였다. FIFO의 평균 결과 나이는 커졌고, 이번 시험의
2스레드 추론은 3스레드보다 빨랐다. 모두 실제 MobileNet-SSD/x264를 사용한 합성
영상 시험이며 실제 카메라·Qt·모터 지연 측정은 아니다.

마지막 요약 단계의 셸 파일 수정 오류를 조사하고 원본 CSV에서 결과를 복구했다.
수정된 전체 스크립트는 조건별 6초 시험으로 다시 검증했다. 제어 코드와 로그 연결은
가짜 pigpio CTest로 확인했다. 오류 조사 내용은 루트 `troubleshotting.md`에 남겼다.

[시험 조건](../performance/README.md),
[예비 결과와 해석](../performance/2026-10-06-results.md)에 상세 내용을 기록했다.
운영 서비스는 기존 실행을 유지했고 설치/재시작하지 않았다. GitHub에는 푸시하지 않았다.
